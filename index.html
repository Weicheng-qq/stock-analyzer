⚙️ AI 分析金鑰（免費）

財務數據(毛利率/營收等)用美國 SEC 官方資料、不需金鑰。但彼得林區分類、競爭對手、護城河、CEO展望、買入建議需要 AI 判讀。支援三種免費金鑰：Gemini（推薦，內容品質最好）、Groq（速度最快）或 OpenRouter。

推薦：取得免費 Gemini 金鑰（不需信用卡，1分鐘）：
1. 前往 aistudio.google.com/apikey
2. 用 Google 帳號登入 → 點 Create API key
3. 複製那串 AIza... 開頭的金鑰，貼到下方

或用免費 Groq 金鑰（速度最快）：
1. 前往 console.groq.com/keys → Create API Key → 複製 gsk_...

或用免費 OpenRouter 金鑰：
1. 前往 openrouter.ai/keys → Create Key → 複製 sk-or-...

金鑰只存在你瀏覽器(localStorage)，不會外傳到我方。使用免費模型，日常分析免費。
