# Skill：股票APP（建立台股版深度分析 APP）

當使用者提到「**股票APP**」，代表要**用建立美股網站的同一套精神與方法，做一個台股版**。請完整沿用 `交接清單/交接清單.md` 的所有原則，只把資料來源換成台股對應的官方來源。

## 一、必須完全沿用的精神（不可打折）

1. **以事實為依據，絕不 AI 臆測**：數字只能來自官方來源，查無的「數字」才可留白，定性欄位用官方年報＋維基組出。
2. **法說會與產品一律「公司官網 IR 優先」**：每間台股公司先從公司官網「投資人關係」找法說會簡報／逐字稿／營運報告，找不到才退回官方公開資訊。
3. **全部免費**：資料來源、AI 模型、部署一律免費／開源；任何可能計費前先問使用者。
4. **一律繁體中文**，專有名詞中譯附英文縮寫。
5. **修正後自我驗證**：改完自己先在瀏覽器操作 golden path 與邊界情況，不能讓使用者測才發現錯。
6. **每季主動更新**：法說會後主動抓官網 IR 更新，不等使用者提醒。
7. **技術架構同款**：單一 HTML 檔（`stock_analyzer_tw.html` === `index.html`）、Vercel 免費部署、`git push` 自動上線、`IR_CALL_SUMMARY`／`IR_PRODUCTS_SUMMARY`／`IR_QUARTERLY_PAGE` 三常數人工判讀寫死。

## 二、台股資料來源對照（全部免費官方）

| 用途 | 美股來源 | 台股對應官方來源 |
|---|---|---|
| 個股報價／基本資料 | Yahoo Finance | 台灣證交所 TWSE OpenAPI（`openapi.twse.com.tw`）、櫃買中心 TPEx OpenAPI |
| 財務報表（10 年） | SEC EDGAR | **公開資訊觀測所 MOPS**（`mops.twse.com.tw`）財務報表、XBRL |
| 法說會（逐字稿／簡報） | 公司官網 IR / SEC 8-K | **公司官網投資人關係**優先；退回 **MOPS「法人說明會」專區**（有簡報 PDF、影音連結）、重大訊息 |
| 產品／營收結構 | 公司官網 IR | 公司官網 IR ＋ **月營收公告（MOPS）** ＋ 年報 |
| 重大訊息 | SEC 8-K | MOPS 即時重大訊息 |

- **代碼**：台股用 4 碼（如 2330 台積電、2317 鴻海、2454 聯發科）；上市走 TWSE、上櫃走 TPEx。
- **幣別**：新台幣，金額換算「億／兆」並標「元（新台幣）」。
- MOPS 抓取常需帶正確表單參數（POST）；官網 PDF 用瀏覽器 cookie ＋桌面 UA curl，`pdftotext -enc UTF-8` 解析。

## 三、建立步驟（照美股同流程）

1. 建 `stock_analyzer_tw.html`（沿用美股版的版面、樣式、`renderAI()` 渲染邏輯，改台股資料源與代碼）。
2. 建 `/api/proxy` 代理抓 MOPS／官網全文（繞 CORS）。
3. 逐間台股公司照「新增一間公司標準流程」建 `IR_CALL_SUMMARY`＋`IR_PRODUCTS_SUMMARY`＋`IR_QUARTERLY_PAGE`：
   - 官網 IR earnings／法說會頁 → 取簡報／逐字稿 PDF → `pdftotext` → 逐項核對寫入。
   - 官網找不到 → 退回 MOPS 法人說明會專區同一份官方簡報。
4. **驗證**：`grep -c "'代碼': {"` = 2；Node.js `new Function` 編譯三常數無語法錯；`cp stock_analyzer_tw.html index.html` 後 `diff -q`。
5. Vercel 免費部署，`git push` 上線，實際在瀏覽器操作驗證。

## 四、預設自選股（建議，可依使用者調整）
台積電(2330)、鴻海(2317)、聯發科(2454)、台達電(2308)、廣達(2382)、聯電(2303)、日月光(3711) 等；預設可放 2330。

## 五、版面與鐵則
- 沿用美股版版面（勿主動改版）；投資哲學文案同款：「以合理低估價格，買入擁有強大護城河的公司」。
- 不加 Service Worker（避免重整迴圈）；保持兩檔一致；能官網就官網、不走捷徑。

> 詳細背景、踩坑、環境注意事項一律參照 `交接清單/交接清單.md`。此 Skill 的目的：讓「做台股版」和「做美股版」是**同一種做法、同一種精神**。
